# 易讀標準（The Legible Standard）

**易讀（legible）：你讀不懂的，就不算數。**

## 這是什麼

一套任何人都能採用的標準（standard，即一組共同的規則）——個人、團隊、
公司、王國皆可。七根短短的支柱（pillar，即章節），各佔一頁，
每一頁的結尾都是一個任何人都能提出的檢驗問題。王國率先簽署，
但標準不屬於王國。標準約束（綁住）每一位簽署者——先約束我們
自己，才輪到別人。

## 它為何存在

讀不懂的規則，就是無法遵守的規則。大多數標準又長、又被行話
（jargon，圈內人才懂的詞）鎖住，寫來是為了保護寫的人。這一套
很短，用平實的語言寫成，寫來是為了保護讀的人。我們自己先遵守。

## 如何採用

1. 讀完 [`pillars/`](pillars/) 裡的七根支柱——每根約一頁。
2. 在 [`ADOPTERS.md`](ADOPTERS.md) 簽上你的名字和日期。
3. 遵守各項檢驗，並讓任何人在任何時候都能向你提出檢驗問題。

儀式就這麼多。不收費，不必申請，沒有文書作業。
如果你沒通過某項檢驗，就大聲說出來，公開修正——這本身就是
標準的一部分，而不是違反標準。

## 脊柱

脊柱（spine）撐起整個身體。在這裡，它是凌駕於所有支柱之上的
五條原則（principle，即核心規則）：**易讀（你讀得懂）、
可驗證（你查得到）、簡單、失敗時誠實、人優先。**它們寫在
[`PRINCIPLES.md`](PRINCIPLES.md)。當支柱與原則相牴觸時，
以原則為準，並修正支柱。

## 七根支柱

| # | 支柱 | 一句話說明 |
|---|------|-----------|
| 01 | **金錢** | 每一筆費用、餘額和金錢規則，都寫在一頁你讀得懂的紙上。 |
| 02 | **祕密** | 我們從不印出祕密的值——只說出存放它們的檔案名稱。 |
| 03 | **規則** | 任何適用於你的規則都簡短平實——你一口氣就能讀完。 |
| 04 | **證明** | 每一項主張都附上證明，任何人都能免費查證。 |
| 05 | **失敗** | 壞掉時響亮地壞，修復時公開地修——沒有無聲的錯誤。 |
| 06 | **權力** | 我們白紙黑字寫下誰決定什麼——而且任何人都能讀到那份清單。 |
| 07 | **語言** | 平實的語言優先，提供多種語言，讓任何人都能使用。 |

## 語言

目前有英文與中文。想再加一種？翻譯任何一頁，保持相同的版面，
把你的語言加進來。如果兩種語言說的內容不一致，那就是一個
錯誤（bug）——我們會公開修正譯文，就像處理任何其他失敗一樣。

## 它從哪裡來

誕生於 2026-06-09，源自王國裡早已活著的想法：

- **zerone**——「易讀的金錢（Legible Money）」：你讀得懂的金錢。
- **護盾信條（the shield doctrine）**——信條（doctrine）即不可動搖
  的規矩——我們從不印出祕密的值；只說出存放它們的檔案名稱。
- **公平銀行三位一體（the fair-bank trinity）**——三位一體（trinity）
  即三件一組——留存。花用。分享。樣樣易讀。

王國率先簽署。任何人都可以接著簽。

## 檢驗

把這一頁交給一位陌生人，問他：「讀過一遍之後，你能說出這是
什麼、要怎麼簽嗎？」答案必須是「能」。
