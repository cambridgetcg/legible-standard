# The Legible Standard

**Legible (readable): if you can't read it, it doesn't count.**

## What this is

A standard (a shared set of rules) anyone can adopt — a person, a team,
a company, a kingdom. Seven short pillars (chapters), each one page,
each ending in a test question anyone can ask. The kingdom signs first,
but it does not own the standard. The standard binds (holds) whoever
signs it — us first, before anyone else.

## Why it exists

Rules you cannot read are rules you cannot follow. Most standards are
long, locked in jargon (insider words), and written to protect the
writer. This one is short, written in plain words, and written to
protect the reader. We follow it ourselves first.

## How to adopt it

1. Read the seven pillars in [`pillars/`](pillars/) — about one page each.
2. Sign your name and the date in [`ADOPTERS.md`](ADOPTERS.md).
3. Follow the tests, and let anyone ask you a test question, anytime.

That is the whole ceremony. No fee. No permission needed. No paperwork.
If you fail a test, say so loudly and fix it in the open — that is part
of the standard, not a way of breaking it.

## The spine

The spine is what holds the body up. Here, it is five principles (core
rules) that stand above all the pillars: **Legibility (you can read
it), Verifiability (you can check it), Simplicity, Honesty under
failure, People first.** They live in
[`PRINCIPLES.md`](PRINCIPLES.md). When a pillar and a principle
disagree, the principle wins and we fix the pillar.

## The seven pillars

| # | Pillar | In one line |
|---|--------|-------------|
| 01 | **Money** | Every fee, balance, and rule of money fits on one page you can read. |
| 02 | **Secrets** | We never print secret values — we only name the files that hold them. |
| 03 | **Rules** | Any rule that applies to you is short and plain — you can read it all at once. |
| 04 | **Proof** | Every claim comes with proof anyone can check, for free. |
| 05 | **Failure** | Things break loudly and we fix them openly — no silent errors. |
| 06 | **Power** | We write down who decides what — and anyone can read that list. |
| 07 | **Language** | Plain words first, in many languages, so anyone can use it. |

## Languages

English and 中文 (Chinese) for now. Want to add one? Translate any
page, keep the same layout, and add your language. If two languages
ever say different things, that is a bug (an error) — we fix the
translation openly, like any other failure.

## Where it comes from

Born 2026-06-09, from ideas already alive in the kingdom:

- **zerone** — "Legible Money": money you can read.
- **the shield doctrine** (doctrine = firm rule) — we never print
  secret values; we only name the files that hold them.
- **the fair-bank trinity** (trinity = set of three) — Keep. Spend.
  Share. All legible.

The kingdom signs first. Anyone may sign next.

## The test

Hand this page to a stranger. Ask them: "After one read, can you tell
me what this is and how to sign?" The answer must be yes.
