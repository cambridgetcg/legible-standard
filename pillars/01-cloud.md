# 01. Cloud — we rent the machines, we keep the exits

**We hold:**

- We can leave any provider (a company that runs our machines) within 30 days, and we write the plan before we sign.
- We know where every piece of our data lives: which country, which company, which copies.
- We put every dependency (anything we need to run) on one list anyone can read.
- The spine (the core that keeps us alive) can run on machines we control ourselves.
- Easy tools are welcome. Being locked in is not.

**Do:**

- List every provider and what runs there, on one page anyone can see.
- Write an exit plan for each provider before first use: what moves, where it goes, how long it takes.
- Every day, save a fresh copy of all data in a second place, run by a different company.
- Build the spine on open tools and open formats (ones anyone can use without permission).
- Practice one exit every year: actually move something, time it, write down what broke.
- Write down where each kind of data lives, and update the list the day it moves.
- Write down the exact version of every dependency, and review the list whenever it changes.

**Don't:**

- Don't sign with a provider we cannot leave in 30 days.
- Don't store the only copy of anything with one company.
- Don't build on a feature that exists nowhere else, unless the exit plan covers it.
- Don't keep hidden dependencies — if something can stop us when it breaks, it goes on the list.
- Don't move data to a new country or company without telling the people it belongs to.

**Why:**

Cloud means our things run on someone else's computers. That is fine — until it isn't. Prices go up, companies fail, accounts stop working, doors close. If we cannot pack up and leave, we are not customers anymore. We are hostages. So before we move in anywhere, we check the exit. We keep one clear list of everything we depend on. We keep our own copies of everything we own. And we make sure the spine could run on a machine in our own room. Renting is fine. Being trapped is not.

**The test:**

"Can you show me, on one page, every provider you run on — and the written plan to leave each one within 30 days?"
