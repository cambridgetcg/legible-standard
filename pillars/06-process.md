# 06. Process — how work gets done, in the open, with the reasons written down

**We hold:** A decision without its written why is half a decision.
**We hold:** Work that no one can see is work that no one can trust.
**We hold:** The best process is the smallest one that still works.
**We hold:** Every task that repeats deserves an owner and a recipe.
**We hold:** If we cannot undo it, we review it before we do it.

**Do:** Write every decision down in one place, with the why beside it, on the same day you make it.
**Do:** Commit (save with a note) small and often, so the trail of work reads like a story.
**Do:** Keep logs (records of what ran and when) for everything that runs on its own.
**Do:** Name one owner for every task that repeats, and write a runbook (a step-by-step recipe) so a stranger could do it tomorrow.
**Do:** Ask "can we undo this?" before you act. If the answer is no, have someone else check it first.
**Do:** Cut a process step the moment it stops helping.
**Do:** Read through the runbooks every few months and delete the ones no one uses anymore.

**Don't:** Don't decide in private chats and announce the result without the reasons.
**Don't:** Don't hide work for weeks and then drop it all at once as one giant surprise.
**Don't:** Don't add a rule, a form, or a meeting when one written sentence is enough.
**Don't:** Don't leave a repeating task without an owner — "everyone's job" is no one's job.
**Don't:** Don't push a change you cannot undo — a deletion, a payment, a release — without review.

**Why:** When you can see how the work happened, and read why someone made each choice, you don't have to trust people's word — you can check the record. New people learn fast, because we wrote the recipes down. Old mistakes don't come back, because the reasons are still there to read. And because we keep the process small, following it is easier than skipping it. That is the whole trick: make the honest path the easy path.

**The test:** Pick any decision from last month — can you find who made it, why, and what happened next, in under five minutes?
